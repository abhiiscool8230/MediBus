# Custom Agent and Skill Documentation

## Custom Agent (`.agent/`)
- **Name**: Medibus Scaffold & Audit Agent
- **Purpose**: A custom Python automation script designed to parse project components, verify that all inventory items properly reflect Indian Rupee formatting, and validate Next.js route configurations.

## Custom Skill (`.skills/`)
- **Name**: Geo-ETA Optimization Skill
- **Purpose**: A specialized script utility that tests Haversine distance calculations against custom coordinate parameters to ensure accurate hospital/clinic travel times.
